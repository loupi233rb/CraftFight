# 双手物品栏

已配置在 `Assets/Prefabs/models/vr_steve.prefab` 的人物上，`Assets/Scenes/MainScene.unity` 使用此角色预制体，左右手各三个槽位。

- 按住 Q / E：分别抬起左手 / 右手查看。
- 滚轮：循环切换最近查看的那只手，松开按键后仍可切换。
- 物品栏始终跟随手腕，金色边框表示选中槽位。
- 左右手各自持有选中槽位的物品；滚轮切换后立即更换，松开 Q/E 后仍然持有。空槽表示空手。

在 `LeftHandInventory` / `RightHandInventory` 的 `HandInventory` 组件中：

- `Item Database` 引用 `Assets/Resources/Data/ItemDatabase.asset`。
- `Item Names` 只保存三个名称字符串，例如 `oak_plank`、`stick`、`iron_ingot`。
- 名称填写数据库中 ItemData 的 `itemName`，不是中文显示名；空字符串表示空槽。
- `Panel Rotation` 调整面板相对相机朝向的旋转偏移，单位为度；X 上下倾斜、Y 左右转向、Z 平面内倾斜，默认全为 0。左右手可分别设置，运行中修改会立即生效；要保留设置，请在退出 Play 后填回数值并保存场景。

渲染关系：`itemNames[index] → itemDatabase.Get(name) → worldPrefab → 槽位模型`。

手持物品使用相同的 `worldPrefab`，目前数据库中的十种物品均直接关联 `Assets/Prefabs/Item/` 下的预制体。手持实例保留原预制体的材质、贴图及模型比例，使用每种物品独立的手持尺寸和朝向；不采用物品栏缩略图的无光照材质，也不修改掉落物的尺寸。

## 握持位置

手持物品挂在每只手的 `HandInventory` 物体下，与相机朝向的物品栏面板分开，跟随手臂运动。使用物品预制体里的 `hand` 子物体作为握持点，对齐其位置和朝向；原始预制体不会被修改。没有 `hand` 时使用预制体根节点作为握持点。

在 `HandInventory` 的 **Hand-held item** 设置中，可分别调整左右手：

- `Held Item Offset`：握持点相对手腕的位置，默认 `(0, 0, -0.08)`。
- `Held Item Rotation`：整只手的额外旋转修正，默认 `(0, 0, 0)`，叠加到物品自己的手持旋转上。
- `Held Item Scale`：整只手的额外尺寸倍率，默认 `1`。

需要调整某一种物品时，在 `Assets/Resources/Data/Item/` 的对应 `ItemData` 资源中修改：

- `Held Item Size`：模型按握持点对齐后、施加物品手持旋转前，包围盒最长边的目标长度。角色比例为 1 时单位为米，保留模型长宽比例。
- `Held Item Rotation`：该物品相对手腕的旋转。
- `Held Item Offset`：该物品额外的位置微调。
- `Enable Held Sword Collider`：持有时启用预制体中已有的 `sword_collider`。

这些手持参数可在运行时调整查看。需要保留时，在退出运行模式后填写回对应资源。物品预制体中的 `hand` 仍决定抓住模型的哪个位置；物品栏的 `Panel Offset` / `Panel Rotation` 只控制面板。

## 持物参考与当前参数

参考了 [Minecraft 原版钻石剑持有截图](https://forums.minecraftforge.net/topic/80930-115-custom-sword-is-not-being-held-properly/)、[打火石第一人称截图](https://www.sportskeeda.com/minecraft/news-how-use-flint-minecraft)，以及 [Minecraft 官方物品显示变换说明](https://learn.microsoft.com/en-us/minecraft/creator/reference/content/blockreference/examples/itemdisplaytransforms?view=minecraft-bedrock-stable)。剑与长杆向前倾斜，材料展示正面，方块缩小后稍作倾斜。下列数值是针对本项目模型、握持点和 Unity 坐标的适配值，并非 Minecraft 原始参数的逐项移植。

| 物品 | 目标最长边 | 旋转 X / Y / Z（度） |
| --- | --- | --- |
| 木剑、铁剑 | 0.85 | 0 / 90 / -65 |
| 木棍 | 0.48 | -65 / 0 / 5 |
| 橡木板、TNT | 0.36 | -15 / 45 / 0 |
| 燧石 | 0.22 | -20 / 25 / -10 |
| 打火石 | 0.28 | -15 / 20 / -10 |
| 铁锭 | 0.28 | -20 / 20 / -8 |
| 铁板 | 0.30 | -10 / 25 / -5 |
| M1911 | 0.38 | 0 / 90 / 0 |

铁板和 M1911 使用本项目的自定义模型；枪械按向前握持适配，不视为原版 Minecraft 的武器。

## 剑的碰撞体

木剑和铁剑持有时，会启用现有 `sword_collider` 子物体及其中的碰撞体，沿用预制体原来的形状和触发器设置，不创建重复碰撞体。忽略剑与角色自身碰撞，切换物品时旧剑立即隐藏并关闭碰撞。其他物品和物品栏缩略图的碰撞仍然关闭，原始预制体中的剑碰撞子物体仍保持未激活。

现有鼠标近战判定保持原样，启用剑的碰撞体本身不会新增接触伤害、开枪、放置或消耗物品的行为。
