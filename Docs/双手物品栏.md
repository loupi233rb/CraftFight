# 双手物品栏

已配置在 `Assets/Scenes/SampleScene.unity` 的人物上，左右手各三个槽位。

- 按住 Q / E：分别抬起左手 / 右手查看。
- 滚轮：循环切换最近查看的那只手，松开按键后仍可切换。
- 物品栏始终跟随手腕，金色边框表示选中槽位。

在 `LeftHandInventory` / `RightHandInventory` 的 `HandInventory` 组件中：

- `Item Database` 引用 `Assets/Data/ItemDatabase.asset`。
- `Item Names` 只保存三个名称字符串，例如 `oak_plank`、`stick`、`iron_ingot`。
- 名称填写数据库中 ItemData 的 `itemName`，不是中文显示名；空字符串表示空槽。

渲染关系：`itemNames[index] → itemDatabase.Get(name) → worldPrefab → 槽位模型`。

当前仅实现三格展示、抬手查看和滚轮切换。
