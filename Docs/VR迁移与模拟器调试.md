# CraftFight VR 迁移与 XR Device Simulator 调试

当前主场景：`Assets/Scenes/MainScene.unity`  
XR 玩家预制体：`Assets/Prefabs/models/xr_steve.prefab`  
环境：Unity 2022.3.62f3c1、XR Interaction Toolkit 2.6.5。已导入同版本 Starter Assets 与 XR Device Simulator。

## 开始调试

1. 打开 MainScene，按 Play，再点击 Game 窗口让它获得输入焦点。
2. 按 Enter 开始游戏；也可以选择模拟手柄，用射线与扳机点击“开始游戏”。
3. 左侧 XR Device Simulator 面板显示当前选中的设备和可用按键。
4. 调试结束后退出 Play。游戏进度和测试产生的物品不会保存到场景。

模拟器对象标记为 EditorOnly，打包时会被剔除。当前无需连接真实 VR 设备，也无需为模拟器启动头显运行环境。

## 键鼠模拟手柄

| 按键 | 用途 |
| --- | --- |
| T / Y | 切换到左 / 右手柄；操作只作用于当前选中的模拟手柄 |
| 按住左 Shift / 空格 | 临时操作左 / 右手柄；空格在 XR 模式下不会开始游戏 |
| Tab | 在模拟设备间循环切换 |
| 按住鼠标右键 | 操作头显视角 |
| U | 切换整体头部 / 身体操控模式 |
| 鼠标移动、滚轮 | 调整选中设备的姿态；具体模式以左侧面板为准 |
| R | 切换旋转 / 平移；左 Ctrl 可临时切换变换模式 |
| WASD、Q/E | 根据当前目标模式模拟摇杆或设备位置 / 高度 |
| 1 | 切换 WASD 是否驱动主摇杆 |
| 3 | 切换 WASD 是否移动选中设备的位置 |
| 鼠标左键 | 选中手柄的扳机：交互、开枪或点击 VR 界面 |
| B | 主按钮：切换该手背包的三个槽位 |
| N | 次按钮：丢弃该手当前槽位的物品 |
| 按住 G | 握持键：抓住锤子；松开释放 |
| 反斜杠 | 切换鼠标锁定 |
| Esc | 停止当前模拟设备操控 |

默认控制目标为主摇杆（Primary2DAxis）。测试实际玩家移动时，选择左手柄，使 1 对应的主摇杆目标开启、3 对应的位置目标关闭，然后使用 WASD。选择右手柄后，A/D 模拟右摇杆左右输入，以默认 60°/秒连续转向，松开摇杆停止。

使用“设备位置”模式是在模拟现实中挪动头或手；用“主摇杆”模式才能验证角色移动与碰撞。左侧模拟器面板可以确认当前模式。

## 游戏交互

- **拾取与背包：** 开始游戏后，用手柄射线指向 5 米内的掉落物，按扳机拾取到该手当前空槽。检测与可见射线使用同一个起点、方向和距离，墙体会阻挡交互。绿色射线与光点表示当前可操作，橙色表示暂时无法操作；顶部会显示物品名称或原因，例如当前槽位已满。当前槽已有物品时不会销毁地上的物品，可按 N 丢弃或用 B 换到空格后再拾取。
- **工作台：** 选中材料，指向空的输入槽，按扳机放入；指向已有材料的槽，按扳机取回。指向工作台实体按钮并按扳机，或用手部检测点触碰按钮，执行合成。输出槽只允许取出。
- **铁砧：** 用扳机放入铁锭；射线指向锤子，按一次扳机即可把锤子拿到该手，松开扳机仍保持持有，移动锤子敲击铁砧会复用原来的速度与碰撞加工逻辑，将铁锭锤成铁板。按该手次按钮（模拟器 N）放下锤子；也保留 G 握持抓取方式。再次用空槽对应的手指向铁砧并按扳机，可取回铁锭或加工完成的铁板。
- **实体工具：** 拿着锤子时，该手的背包与拳头攻击判定暂时禁用，原有物品保留；点按拿取后按次按钮放下，握持抓取则松开握持键放下，随后恢复该手物品栏。
- **战斗：** 装备 M1911 手枪的那只手按扳机开枪，每按一次发射一枪，长按不会连发。默认每枪 10 点伤害、40 米射程、0.25 秒射击间隔，枪口闪光、弹道和枪声会同时反馈；攻击升级也会增加枪伤。墙体阻挡子弹。指向 VR 界面时仍然点击按钮，不会开枪；持枪时与物品交互请换空槽或使用另一只手。未持枪时，扳机只用于场景交互，不再触发近战或射线伤害。木剑、铁剑使用各自原有 sword_collider 剑刃碰撞箱，接触怪物即造成伤害并沿用怪物受伤、音效和击退流程，不要求最低挥动速度。左右手末端各有一个 0.18 米拳头触发框，只有当前槽为空且没有抓住工具时启用，拳头与剑共用 CraftXRContactDamage 判定。一次接触仅结算一次，同一怪物多个碰撞体不会重复计伤；分开后重新接触可再次攻击，仍受 SteveMeleeAttack 的默认 0.625 秒共享冷却限制，默认伤害 6，攻击升级继续生效。死亡、交易和移动暂停期间不会造成接触伤害。
- **交易：** 靠近村民并用手柄射线按扳机打开交易。用射线点击升级项或关闭按钮。面板在玩家面前显示，交易期间暂停游戏移动和背包操作。
- **状态：** 血量、金币、倒计时、关卡提示和怪物血量使用世界空间显示。
- **关卡：** 等待、准备、战斗、传送和三关完成继续使用原有规则。每关怪物全部击败后，留在战斗区 5 秒拾取金币；期间可以正常移动，状态面板显示返回倒计时，结束后才回到合成区。最后一关同样等待拾取后再完成游戏。战斗时间耗尽仍按原有规则返回；等待时长可在 GameFlowTimer 的 Loot Duration 调整。桌面鼠标视角、旧头手跟踪和旧屏幕界面在 XR 模式下退出控制。

## 验证与维护

- `Tools > CraftFight > Validate XR migration`：检查 XR 场景绑定、摄像机、音频监听器、双手、模拟器和 UI 等，结果写入 `Docs/XRMigrationValidation.txt`。
- 进入 Play 后，使用 `Tools > CraftFight > Run XR simulator integration checks`：用与模拟器相同的模拟 XR 设备布局执行交互检查，结果写入 `Docs/XRPlayModeValidation.txt`。此检查会修改本次运行的物品、金币和关卡，完成后退出 Play 再开始正常调试。
- `Docs/XRValidation/` 保存运行画面检查截图。
- 原始场景和修改前脚本备份位于 `.codex-backups/vr-migration-20261030/`。
- `CraftXRMigration.Configure` 用于未迁移场景的首次配置；已经迁移的主场景无需重复配置。

自动回归验证了 Unity Editor 内的模拟设备输入、运行逻辑与画面。电脑串流已识别 SteamVR/OpenXR 头显，用户已确认切回游戏后能看到手柄；实际佩戴高度、头手对齐与连续转向舒适度仍需佩戴确认。Android 真机性能与打包运行尚未验证。

## M1911 射击调试

进入 Play，按 Enter 开始游戏，Y 选择右手柄，然后按两次 B 选中初始右手第三格的手枪。调整手柄朝向后按鼠标左键（模拟扳机）开枪。左右手装备手枪后都可独立射击；未加入弹药与换弹限制。枪械数值和枪声音效可在 Assets/Resources/Data/Item/m1911.asset 中调整。

手持橡木板最长边已调整为 0.16 米（原 0.36 米），仅缩小手持显示；世界掉落物和工作台材料模型保持原来的大小。

## 电脑串流 / Link 真机运行

先连接串流、确认 SteamVR 中头显和两只手柄在线，再进入 Unity Play。桌面端 OpenXR 已开启自动初始化，并配置常见 SteamVR 手柄交互配置。戴上头显后应回到 Unity 游戏画面，关闭 SteamVR 仪表盘，使 OpenXR 会话获得前台输入焦点。

XR Simulation Mode (Editor only) 的 Input Mode 默认为 Auto：发现真实头显时停用整个模拟器；没有设备时自动启用模拟器。模拟器不会再移除真实头显设备。需要明确离线调试时可选择 Simulator；明确使用头显时可选择 Headset。

真机优先使用 Floor 原点，头和双手共用 Camera Offset，地面空间不再额外加 1.67 米；不支持 Floor 时回退 Device 原点。模拟器使用 Device 原点与一份 1.67 米身高补偿。关卡传送只移动角色的地面位置，保留物理头部高度与下蹲，不再在首帧猜测眼高。

右摇杆已从 30° 分段转向改为连续转向，速度可在 XR Steve 下的 Locomotion System / Turn 中，通过 Continuous Turn Provider 的 Turn Speed 调整。


XR 双手的手持物品已绕握持轴翻正，木剑和铁剑的剑尖沿手臂前方伸出，剑刃碰撞箱同步跟随，枪口继续沿控制器前方。三格物品栏位于手背上方约 0.14 米、向手腕后方约 0.2 米，面板朝上，三个格子沿手臂前后排列；这些姿态保存在 XR Steve 场景与预制体中，修复配置菜单也会保留此设置。
