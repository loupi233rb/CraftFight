# 玩家、村民、物品选择和背景音乐

配置资产：`Assets/Resources/Audio/GameAudioSettings.asset`。在 Unity Project 中选中它即可调整素材、各类音量、脚步间距、村民叫声间隔和音乐淡入淡出时间。不要移出 Resources/Audio 或更改资产名称，运行时按此路径加载。

原始素材来自 `D:\课程\大三上\vr\audio`，已复制进工程，不依赖电脑上的原目录。新增音频放在 `Assets/Audio/Player`、`UI`、`Villager`、`Music`。

- 玩家：`SteveHealth.Awake` 自动添加 `PlayerAudio`，现有场景和后来实例化的玩家均生效；脚步按实际水平行走距离触发，默认每 1.4 米一步，两段素材交替变化。站立、撞墙、腾空、击退、交易期间和死亡不触发新脚步；有效伤害（含致命伤害）播放受伤声。
- 物品：`HandInventory.Cycle` 切换选中格时播放点击声；不会因每帧刷新模型重复发声，也不会把普通攻击点击当作物品选择。
- 村民：`VillagerTrader.Awake` 自动添加 `VillagerAudio`。默认每 6–12 秒哼声，打开交易时问候，购买成功播放 yes，金币不足播放 no；村民声音为 3D 音效，2 米内原音量，16 米处衰减到零。
- 音乐：活着且位于 NavMesh 上的怪物正追逐当前玩家时循环 Insistent。最后一个威胁消失约 3–3.5 秒后切到 Exploration Theme。两曲用 1.5 秒交叉淡入淡出，初始音量 0.22；死亡后淡出。当前 AI 没有警戒范围，怪物持续追逐，因此不会仅因距离变远而退出战斗。

玩家声音、选择声和音乐为 2D 音频，独立音源避免彼此打断；两首音乐以流式方式导入，保留立体声。无需手动在场景挂载新增组件，已有 MonsterAudio 配置不受影响。

Exploration Theme 随附 CC0 许可说明，保留在 `Music/Exploration_Theme_LICENSE.txt`。

## 手动验收

运行后移动、停止并撞墙，确认只有实际行走时出现脚步；受到怪物伤害时检查受伤声。滚轮切换左右手选中格，检查每次切换只响一次。靠近村民等待哼声，按 F 打开交易，检查购买成功和金币不足的回应。击败所有怪物，确认战斗音乐淡出、探索音乐淡入；玩家死亡时音乐淡出。
