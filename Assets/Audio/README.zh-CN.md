## 替换某一类音效（推荐）

1. 退出 Play Mode。
2. 将新 `.wav`、`.ogg` 或 `.mp3` 文件拖进 Unity Project 窗口中的 `Assets/Audio/Monsters/Zombie` 或 `Skeleton` 文件夹，等待导入完成。新文件不需要遵循现有命名规则。
3. 在 Project 窗口选中 `Assets/Audio/Profiles/ZombieAudio.asset` 或 `SkeletonAudio.asset`。
4. 在 Inspector 展开要替换的类别：**环境叫声、脚步、近战挥动、受击、死亡、射箭、箭命中**，把新 AudioClip 拖到相应数组的 `Element 0`、`Element 1` 等位置。
5. 若只有一个新素材，将数组的数量设为 `1`；若有多个变体，将数量增大并逐项拖入，播放时会随机选择。将某类数组数量设为 `0` 可关闭该类声音。
6. 进入 Play Mode 检查对应行为。配置资产的修改由 Unity 保存，提交项目时也需要带上新音频文件及其 `.meta`。

## 保持现有引用，直接替换文件

也可以在文件管理器中用新音频覆盖 `Assets/Audio/Monsters` 中某个现有文件，保留原文件名、真实音频格式和旁边的 `.meta` 文件，返回 Unity 等待重新导入即可。不要先删除旧资产再创建同名文件，否则 GUID 可能变化，原来的配置引用会丢失。不同格式请使用上面的 Inspector 拖入方式，例如新 WAV 不要只改成 `.ogg` 后缀。

## 调整音量、频率和听觉距离

同一个配置资产的 Inspector 中可以修改：

- **总音量**：控制该怪物全部音效；**叫声音量、脚步音量、战斗音量**：分别控制对应类别。
- **叫声间隔（秒）**：两个值为随机间隔的最小值和最大值，当前为 `4–8` 秒。
- **每步距离（米）**：调小会更频繁地产生脚步声，当前僵尸为 `1.1`、骷髅为 `1.3`。
- **音高变化范围**：当前为 `0.95–1.05`，改为 `1–1` 可使用原始音高。
- **开始衰减距离（米） / 最远可听距离（米）**：当前为 `1.5 / 24`，声音越远越小。

新导入的 3D 怪物音效建议在 AudioClip 的导入 Inspector 中启用 **Force To Mono**，短音效使用 **Decompress On Load**，并启用 **Preload Audio Data**，然后点击 **Apply**。本次导入的素材已设置好。

## 只改一个怪物，或给新怪物使用配置

场景 `SampleScene` 中的 `vr_zombie` 和 `vr_skeleton` 已带有 **Monster Audio** 组件，其中 **音效配置** 指向对应资产。多个怪物可以共用一个配置；修改该资产会影响所有引用它的怪物。

如果只想给一个怪物不同的声音，先在 Project 窗口复制配置资产，再选中该怪物，把副本拖到 **Monster Audio → 音效配置**，并保存场景。复制现有已配置怪物对象也会保留音效设置。

## 没有声音时

确认类别数组已填入 AudioClip、各音量大于 `0`，怪物的 **Monster Audio → 音效配置** 已指定，Game 窗口没有启用 **Mute Audio**，玩家相机的 AudioListener 已启用，并且玩家位于最远可听距离内。选中新素材可先在导入 Inspector 的预览区试听。
