# CraftFight
- 使用unity开发的一款基于PICO 4 Ultra的vr小游戏
- 对应课程 虚拟现实
- 基本玩法使用手工合成的物品道具与怪物进行战斗

## 基本信息

### 操作
电脑调试端使用Simulator

PICO端
|  | 左手 | 右手 |
| ---- | ---- | ---- |
| **交互** | `左扳机` | `右扳机` |
| **丢弃** | `Y` | `B` |
| **切换物品栏** | `X` | `A` |
| **移动** | `左摇杆` | \ |
| **转动视角** | \ | `右摇杆` |

### 物品栏
- 每只手各有三个物品栏槽位，每槽位只能放一个物品
- `扳机` 进行交互，包括对应手槽位的拾取和取出
- 当拿起 `锤子` 后，物品栏会无法使用，直到按下 `Y` 或 `B` 放下

### 合成玩法
- `工作台` 旁的物品生成器每一关会提供限量的物资
- 使用物品按照墙壁上的提示来摆放物品
- 只有当摆放正确时与 `按钮` 交互才会合成
- `铁砧` 内只能放入铁锭，使用 `锤子` 敲打至一定程度后能够合成 `铁板`
- `工作台` 的输出格子只能取出无法放入物品
- 战斗中怪物会掉落 `金币` ，在 `村民` 身边进行交互可以升级自身属性

### 战斗玩法
- 怪物每波刷新，包括 `僵尸` 和 远程的 `骷髅` 
- 存活至倒计时结束或将怪物全部击杀即为胜利
- `木剑` 和 `铁剑`的伤害与挥击速度相关 
- 场景内有障碍物可进行拉扯
